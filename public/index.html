        How to play

        1. Each round shows one to three small tables and a target result.
        2. Write a SELECT that produces the target. The live preview runs your query as you type.
        3. Same columns in the same order, same rows. Column names don't matter. Row order only matters when the puzzle says order matters.
        4. Submit with the button or Ctrl/⌘+Enter. Wrong tries are fine (one every 2 seconds) but everyone sees how many you made.
        5. First correct: 5 points, second: 3, later: 1. The shortest correct query of the round gets +1.

        Supported: SELECT, DISTINCT, FROM, JOIN … ON, WHERE, GROUP BY, HAVING, ORDER BY, LIMIT/OFFSET, count/sum/avg/min/max, lower/upper/length/abs/round/coalesce, LIKE, IN, BETWEEN, IS NULL.
